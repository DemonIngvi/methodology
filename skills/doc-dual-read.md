# Проверка двумя читателями

Правило — `rules/dual-read.md`.

1. Собрать опубликованные страницы (сборка документации).
2. Снимок для читателей (без доступа к исходникам): со страниц компонентов — разделы «Контракты данных»; с главной — термины, типы данных, интерфейсы; правило имён (`rules/data.md#naming`). Сохранить во временную папку вне репозитория.
3. Запустить **двух** агентов независимо, одинаковым заданием: читать только снимок; на каждую модель — что это, кто → кому, почему такая структура, почему такие имена, неясные поля, противоречия; на каждый I-код — кто вызывает кого, что туда и обратно, зачем; общие неясности. «Чего нет — пиши «в тексте нет», не додумывай».
4. Сравнить по смыслу: совпало · разошлось · совпало, но не так · непонятно. Всё, кроме «совпало», исправить **в источнике** (файл данных, каталог API, решения) — решения только из существующих D / R, иначе вопрос в спеке.
5. Повторять, пока объяснения не совпадут. Протокол — `reviews/<дата>-dual-read.md`.
