# Новое R&D

1. Заготовка: `rnd <slug> <тема>` — файл со структурой v3.1 (первая страница, Э1–Э10, ворота G1–G10). Без инструмента — скопировать `templates/rnd.md`.
2. Строка в реестре R&D (тема, вопрос, статус, версия методологии `v3.1`).
3. Этапы — по `rules/rnd.md`: открывать раздел нужного этапа, а не весь файл. Факты — с источником и датой; код и спецификация API существующей системы — уровень А.
4. Э10 «Последствия»: каждая строка — документ и статус ✅ / 📌 / —; внести решение (D-номер) и все последствия (спеки, файл данных, API, «Как работает», Deploy, задачи, технологии) по `rules/change-process.md`.
5. Проверка: `check` (структура R&D), затем сборка.
