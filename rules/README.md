## Короткое правило

Любое изменение документации: **тип документа → его методология → источник факта → правка → связанные документы по графу → проверки → коммит**.

## Общие правила для всех документов

- В начале файла — строка «←» со ссылкой на родителя.
- Все упоминания других документов — ссылками.
- Схемы — mermaid по [формату схем](diagrams.md).
- Секретов нет.
- Язык документов выбирается проектом и одинаков во всех документах; ключевые слова форматов (SHALL / MUST, заголовки формата спек) — как в формате.
