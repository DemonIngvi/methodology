# Блок: Экспорт счетов

← [архитектура](../../../architecture.md) · [спека](../../../specs/billing/spec.md)

**Тип:** блок · **Вид:** сервис

| Поле | Значение |
|---|---|
| Что делает | — выгружает счета периода в CSV<br>— отправляет счёт клиенту |
| Технология | Python 3.12 |
| Истории | US-BIL-1 |
| Входы и выходы | ← бухгалтер: период<br>→ почтовый сервис: I1 |
| Данные | `invoices` — чтение |
| Параметры | `export.max_rows` |
| Требования | R-BIL-1, R-BIL-2 |
| Задачи | 1.1 |
| При сбое | почтовый сервис недоступен → 3 повтора, затем «не отправлен» |
| Почему так | CSV принимает учётная система бухгалтерии · D-1 |

## Операции

| Операция (эндпоинт или функция) | Кто вызывает | I-код или «внутри» |
|---|---|---|
| `GET /invoices/export?from&to` | интерфейс бухгалтера | внутри |
| `send_invoice(id)` | планировщик | I1 |
