# Расход токенов

← [как замерять](../../rules/token-costs.md#measure)

Сколько токенов уходит на единицу работы по процессам: ожидание против замера. Страница **генерируется** из `data/costs.yaml` (`python ../../tools/doc cost md`); новая запись — `python ../../tools/doc cost add …`, сводка — `python ../../tools/doc cost`. Допуск ±2×: вне его — ⚠️, остановиться и разобрать.
