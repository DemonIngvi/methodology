# Deploy: billing

← [архитектура](../architecture.md) · [параметры](../specs/billing/interfaces.md)

## Образы

`billing:1.0` — Python 3.12, собирается из `Dockerfile` репозитория.

## Запуск

Один контейнер; порт 8080.

## Переменные и секреты

| Переменная | Что | Секрет |
|---|---|---|
| `EXPORT_MAX_ROWS` | параметр `export.max_rows` (значение — в спеке) | нет |
| `MAIL_TOKEN` | токен почтового сервиса (I1) | да |

## Сборка и поставка

Сборка в CI по тегу; образ — в реестр проекта.

## Проверка после развёртывания

`GET /health` → 200; тестовый экспорт пустого периода → CSV с заголовком.

## Обновление и откат

Миграции обратимые; откат — предыдущий тег образа.
